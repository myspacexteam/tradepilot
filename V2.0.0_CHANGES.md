# TradePilot 2.0.0

## New

- **TradePilot Market Lab — first analysis-panel prototype**.
  - A slim gold arrow on the Windows Connector opens/closes a dedicated
    Microsoft Edge app window beside the connector.
  - Embedded TradingView Advanced Chart with a professional TradePilot shell.
  - Strategy presets: Clean Chart, EMA Trend, EMA + MACD, RSI Momentum, and
    Bollinger + RSI.
  - Reference symbols for major FX, gold, indices, and BTC.
  - M1, M5, M15, H1, and H4 timeframe controls.
  - Analysis only: no duplicate trade controls in this prototype.
  - The chart is clearly labeled as a reference feed because OANDA is not
    Exness.
- **Premium visual refinement** across the trading console.
  - Layered midnight surfaces, champagne-gold accents, restrained depth, and
    higher-quality control states.
  - Refined trade buttons, quote header, inputs, lot controller, status
    surfaces, selective-close area, advanced panel, and feedback toast.
- **Five distinct command sound signatures**.
  - BUY uses a short rising confirmation.
  - SELL uses a lower descending confirmation.
  - CLOSE POSITION uses a layered cash-register/order-complete chime.
  - CLOSE WINNERS uses an uplifting three-note chime.
  - CLOSE LOSERS uses a subdued descending three-note chime.
- **Safer selective-close placement**.
  - `CLOSE WINNERS` and `CLOSE LOSERS` now sit directly below
    `CLOSE POSITION`.
  - A doubled safety gap, divider, and warning label separate the actions.
- **Automatic Windows setup-QR renewal**.
  - The displayed phone QR renews 15 seconds before expiry.
  - Failed QR generation retries automatically after 15 seconds.
  - Expired and already-used setup tokens are cleaned from the local database.
- **Premium command feedback**.
  - BUY, SELL, CLOSE POSITION, CLOSE WINNERS, and CLOSE LOSERS play a short
    synthesized click with distinct pitch.
  - A 220 ms press animation reinforces that the tap was received.
- **Minimal premium status header**.
  - Active Sydney, Tokyo, London, and New York session indicator.
  - Live local time with seconds.
  - MT5 connection state.
  - All three items stay on one compact line.
- Removed the in-app TradePilot logo, candle countdown, M1/M5 selector, second
  status banner, and Keep Awake control for a cleaner trading screen.
- **Live MT5 symbol catalogue**.
  - Reads tradeable symbols directly from the connected MT5 terminal.
  - Supports broker-specific names and suffixes such as `EURUSDm`, `XAUUSDm`,
    indices, metals, energies, stocks, and crypto when offered by that account.
  - The refresh button reloads the list from MT5.
  - Version 1.4.1 replaces the browser datalist with a full searchable symbol
    picker, so tapping the symbol field and searching `EURUSD` shows all broker
    variants instead of only the currently selected symbol.
- Lot controls now use the selected symbol's minimum volume and volume step.

## Safety and behavior

- Demo-only protection remains enabled.
- Selecting a symbol does not guarantee that its market is open.
- If the user manually locks the phone or leaves the browser, mobile operating
  systems may suspend the page. Keep Screen Awake is intended to prevent the
  normal automatic screen timeout while TradePilot is visible.

## Build

1. Exit TradePilot.
2. Copy this package over the existing Builder folder and replace files.
3. Run `BUILD_INSTALLER.bat`.
4. Install `release\TradePilotSetup.exe`.
5. Open MT5 Demo, launch TradePilot, scan a new QR, and test.
