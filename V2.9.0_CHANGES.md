# TradePilot 2.9.0 — Signal Fusion Phase One

- Renamed the existing Premium Strategy menu item to FLOW PULSE.
- Added SIGNAL FUSION as the third Analysis Menu item.
- Added a closed-candle Signal Fusion endpoint for M1, M5 and M15.
- Added MACD 12/26/9 EMA regime with configurable separation hysteresis.
- Added a per-candle MACD state lane: bullish, bearish or neutral.
- Added a Candle Pressure lane using body, close location, ATR expansion,
  close-to-close momentum and wick rejection.
- Candle Pressure colors include strong, medium, weak and neutral intensities.
- Neutral pressure is explicitly marked as NO ENTRY.
- Added Arabic and English UI support.

Signal Fusion is analysis-only and never sends an order.
