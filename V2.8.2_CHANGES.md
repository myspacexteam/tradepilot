# TradePilot 2.8.2 — M5 Minimum and Language Switch

- Removed the one-minute timeframe from Premium Strategy display and mode weighting.
- FAST now uses M5 as primary and M15 as confirmation.
- Added an Arabic / English language selector to the Flow Chart.
- Removed the historical alternative path and all historical-path labels from the chart.
- The dotted future movement now follows only the conditional scenario geometry:
  current price → confirmation trigger → TP1 → TP2.
- Added a non-historical visual uncertainty corridor around the conditional path.
- Historical analogue calculations may remain internal to setup validation, but are no longer drawn or presented as a price path.

The future path is a conditional scenario, not guaranteed future market data.
