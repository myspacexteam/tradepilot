# TradePilot 2.5.0

## New

- **Configurable Shark grids**.
  - SHARK BUY opens a 0.03 market buy plus three Buy Stop levels above it.
  - SHARK SELL opens a 0.03 market sell plus three Sell Stop levels below it.
  - Default nearest-to-farthest lots are 0.03, 0.02, 0.01, and 0.01.
  - A dedicated hidden Shark Settings panel controls all four lots and spacing.
  - Settings persist on the device, and MT5 enforces the broker minimum distance.
- **Cleaner Market Lab chart**.
  - Removed the floating Entry / TP / SL position card while retaining live performance statistics.
- **Matching Market Lab app icon**.
  - The Edge app window now advertises the same gold TP icon as the Connector.
  - Adds both ICO and PNG favicon declarations to avoid the generic globe icon.
- **Compact mobile performance strip**.
  - Adds the same live MT5 performance summary directly below the phone header.
  - Fits Today Pips, Balance, Equity, Closed P/L, Gross Win, Gross Loss,
    Winners/Losers, and Open P/L on one responsive line without horizontal
    scrolling.
- **One-line MT5 performance strip**.
  - Today pips, balance, equity, closed P/L, gross win, gross loss, closed winners/losers, and open P/L.
  - Values refresh from MT5 every 2.5 seconds and use clear profit/loss colors.
- **Reliable upgrades**.
  - The builder deletes stale web output and verifies the MT5 position overlay.
  - The installer stops an older tray instance before replacing files.
  - Market Lab displays its version so the running build can be confirmed.
- **Stable separate Market Lab window**.
  - The gold arrow opens Market Lab beside the Connector without resizing it.
  - Pressing the arrow again closes Market Lab.
  - Removed experimental Edge window embedding that could produce a large black surface.
- **Live MT5 position overlay in Market Lab**.
  - Shows the matching open trade ticket, direction, volume, entry price, TP, and SL inside the chart area.
  - Refreshes automatically from the local MT5 Connector every 2.5 seconds.
- **Control order refinement**.
  - Chart Style now appears before Strategy / Indicators.
- **Readable native dropdown menus**.
  - Open select menus use a light background with explicit dark option text,
    fixing white-on-white labels on Windows.
- **Market Lab Pro controls**.
  - Nine indicator/strategy presets built from EMA, MACD, RSI, and Bollinger
    Bands combinations.
  - Candles, Hollow Candles, Heikin Ashi, Line, Area, and Baseline chart styles.
  - Expanded reference-symbol list for majors, gold, indices, and BTC.
  - Exchange, UTC, London, New York, and Tokyo timezone choices.
  - Fullscreen mode.
  - Automatic persistence of the last preset, chart style, symbol, timezone,
    and timeframe.
  - Clear active-preset badge inside the chart.
- **TradePilot Market Lab analysis window**.
  - A slim gold arrow opens/closes a dedicated Microsoft Edge app window.
  - TradingView Advanced Chart with a professional TradePilot shell.
  - Strategy presets, reference symbols, and M1/M5/M15/H1/H4 controls.
  - Analysis only: trading controls remain in the TradePilot web app.
  - The chart is clearly labeled as a reference feed because OANDA is not
    Exness.
- **Premium visual refinement** across the trading console.
  - Layered midnight surfaces, champagne-gold accents, restrained depth, and
    higher-quality control states.
  - Refined trade buttons, quote header, inputs, lot controller, status
    surfaces, selective-close area, advanced panel, and feedback toast.
- **Five distinct command sound signatures**.
  - BUY uses a short rising confirmation.
  - SELL uses a lower descending confirmation.
  - CLOSE POSITION uses a layered cash-register/order-complete chime.
  - CLOSE WINNERS uses an uplifting three-note chime.
  - CLOSE LOSERS uses a subdued descending three-note chime.
- **Safer selective-close placement**.
  - `CLOSE WINNERS` and `CLOSE LOSERS` now sit directly below
    `CLOSE POSITION`.
  - A doubled safety gap, divider, and warning label separate the actions.
- **Automatic Windows setup-QR renewal**.
  - The displayed phone QR renews 15 seconds before expiry.
  - Failed QR generation retries automatically after 15 seconds.
  - Expired and already-used setup tokens are cleaned from the local database.
- **Premium command feedback**.
  - BUY, SELL, CLOSE POSITION, CLOSE WINNERS, and CLOSE LOSERS play a short
    synthesized click with distinct pitch.
  - A 220 ms press animation reinforces that the tap was received.
- **Minimal premium status header**.
  - Active Sydney, Tokyo, London, and New York session indicator.
  - Live local time with seconds.
  - MT5 connection state.
  - All three items stay on one compact line.
- Removed the in-app TradePilot logo, candle countdown, M1/M5 selector, second
  status banner, and Keep Awake control for a cleaner trading screen.
- **Live MT5 symbol catalogue**.
  - Reads tradeable symbols directly from the connected MT5 terminal.
  - Supports broker-specific names and suffixes such as `EURUSDm`, `XAUUSDm`,
    indices, metals, energies, stocks, and crypto when offered by that account.
  - The refresh button reloads the list from MT5.
  - Version 1.4.1 replaces the browser datalist with a full searchable symbol
    picker, so tapping the symbol field and searching `EURUSD` shows all broker
    variants instead of only the currently selected symbol.
- Lot controls now use the selected symbol's minimum volume and volume step.

## Safety and behavior

- Demo-only protection remains enabled.
- Selecting a symbol does not guarantee that its market is open.
- If the user manually locks the phone or leaves the browser, mobile operating
  systems may suspend the page. Keep Screen Awake is intended to prevent the
  normal automatic screen timeout while TradePilot is visible.

## Build

1. Exit TradePilot.
2. Copy this package over the existing Builder folder and replace files.
3. Run `BUILD_INSTALLER.bat`.
4. Install `release\TradePilotSetup.exe`.
5. Open MT5 Demo, launch TradePilot, scan a new QR, and test.
