# TradePilot 1.4.0

## New

- **Keep Screen Awake** control in the PWA header.
  - Uses the Screen Wake Lock API when the browser and connection support it.
  - Uses a tiny local looping-video fallback for iPhone/HTTP sessions.
  - The control must be enabled once after opening or refreshing the page.
- **Live MT5 symbol catalogue**.
  - Reads tradeable symbols directly from the connected MT5 terminal.
  - Supports broker-specific names and suffixes such as `EURUSDm`, `XAUUSDm`,
    indices, metals, energies, stocks, and crypto when offered by that account.
  - The refresh button reloads the list from MT5.
- Lot controls now use the selected symbol's minimum volume and volume step.

## Safety and behavior

- Demo-only protection remains enabled.
- Selecting a symbol does not guarantee that its market is open.
- If the user manually locks the phone or leaves the browser, mobile operating
  systems may suspend the page. Keep Screen Awake is intended to prevent the
  normal automatic screen timeout while TradePilot is visible.

## Build

1. Exit TradePilot.
2. Copy this package over the existing Builder folder and replace files.
3. Run `BUILD_INSTALLER.bat`.
4. Install `release\TradePilotSetup.exe`.
5. Open MT5 Demo, launch TradePilot, scan a new QR, and test.
