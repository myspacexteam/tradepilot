# TradePilot 2.9.1 — Multi-Timeframe Signal Fusion

- Added five compact MACD regime lanes: D1, H4, H1, M15 and M5.
- Regime lanes now show the minimum-separation transition zone in gray.
- Confirmed bullish and bearish zones remain green and red.
- Candle-state and Candle Pressure lanes use a selectable execution timeframe.
- Removed M1 from Signal Fusion timeframe choices.
- Candle Pressure now uses one fixed green hue and one fixed red hue;
  strength changes only color darkness/lightness.
- Expanded the neutral Candle Pressure threshold to make NO ENTRY areas clearer.
- Balanced MACD separation now defaults to 0.25.
